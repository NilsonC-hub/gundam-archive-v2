# RX-79[G] 机体交互档案 · V2

陆战型高达的浏览器交互展示。转动机体、查看装备，播放战术动作、举盾防御和举枪射击，并阅读机体与第 08 MS 小队的故事。

本仓库提供 V2 单版及其运行资源，可独立获取和启动。

## 运行

需要 Node.js 22.12 或更高版本，也兼容 Node.js 20.19 系列。首次在项目目录执行：

```sh
npm ci
npm run build
npm run preview
```

浏览器打开 <http://127.0.0.1:4183/>。开发时使用 `npm run dev`。

Windows 也可双击 `打开设计样板.cmd`。该入口需要已完成构建、已安装 Python 3，并且 `python` 命令可用；会复用已启动的本项目服务。修改源文件后，重新运行 `npm run build`。

构建输出 `dist`、依赖和缓存由本地生成，不上传仓库。项目按网站根路径运行；GitHub 仓库地址是源码页面，目前未启用 GitHub Pages。

## 交互与画面

- 机体支持转动、缩放、整机及局部观察、线框与自动旋转。
- 三组动作：战术动作、举盾防御、举枪射击。
- 射击演示约 5.2 秒，三发子弹依次产生弹孔，随后裂纹扩展、玻璃碎片飞散。配有步枪、玻璃撞击和碎裂录音。
- 玻璃使用 Three.js 几何和着色器，读取当前画面表现折射、轻微色散、环境反射与薄边。
- 支持清除效果、静态观看和减少动态偏好。
- 机体档案包含开发背景、武装、作品、人物、小队及结局。

玻璃为实时屏幕空间效果，取样范围是当前视窗。运行需要支持 WebGL 的现代浏览器。模型约 9.92 MB，首次加载需等待；Three.js 主包会产生超过 500 KB 的构建体积提示。
